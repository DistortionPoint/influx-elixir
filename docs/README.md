# Documentation

Static Markdown; no build step. Module and function documentation lives in
the code (`@moduledoc` / `@doc`) and is published to HexDocs by `mix docs`.

| Directory | Contents |
|---|---|
| [`design/`](design/README.md) | Dated design documents: one per change that needed a decision, with the verification that closed it |
| [`guides/`](guides/README.md) | Consumer-facing guides published as HexDocs extras |

Conventions for both are in each directory's README. The project-wide
standards (kebab-case filenames, working examples, H1 title / H2 sections,
keep in sync with the code) are in `CLAUDE.md`.
